# Manejo-de-archivos-en-C-
ejercicios del 4-7
Respuestas del 4-7:  

Ejercicio 4:
Se usa un archivo CSV (texto plano separado por comas). Es conveniente porque los datos son tabulares (nombre, asignatura, nota), son sencillos de leer línea por línea, y no requieren librerías especiales en C#. Su ventaja es que es liviano, legible por humanos y compatible con cualquier editor o Excel.
Ejercicio 5: 
También CSV. Cada venta es un registro con campos fijos (producto, cantidad, precio, fecha), lo que encaja perfectamente con el formato de filas y columnas. Permite agregar registros nuevos sin perder los anteriores gracias al modo append.
Ejercicio 6:
 Los contactos tienen siempre los mismos tres campos (nombre, teléfono, correo), por lo que un archivo plano estructurado es suficiente y eficiente. No se necesita un formato más complejo como JSON o una base de datos.
 Ejercicio 7:
 Los datos son simples: día y temperatura. Un archivo de texto con dos columnas es más que suficiente, fácil de leer, y permite calcular el promedio sin necesidad de estructuras complejas.
